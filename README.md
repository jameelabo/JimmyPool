# Jimmy Pool 🎱

An offline 3D pool game for Android against the computer. English is the default language, with Arabic available from the game menu.

## Download

**[Download Jimmy Pool 1.1 for Android](https://raw.githubusercontent.com/jameelabo/JimmyPool/main/JimmyPool-v1.1.apk)**

- Requires Android 8.0 or newer.
- Download and open the APK. If Android asks, allow installation from the app used to open it.
- Install updates over your current copy without uninstalling to preserve your match and wins.
- Menu → Language switches between English and Arabic and remembers your choice.

## Features

- 3D table, 16 balls, six pockets and two camera angles.
- Touch to aim, drag back from the cue ball or use the slider to set power, then tap Shoot.
- Computer opponent with Easy and Normal difficulty.
- Local sound effects, automatic match saving and win counts.
- Ball-in-hand placement after fouls.

## Rules

A casual 8-ball variant: clear your solids or stripes, then legally pot the 8-ball. Potting it early or with a foul loses; it is respotted when potted on the break. Called pockets, cue spin and online multiplayer are not included.

## Browser edition

[Download the self-contained HTML game](JimmyPool.html?raw=true) and open it in a browser with WebGL support. Browser saves are separate from Android saves and do not synchronize.

## Technical details

- Android package: `com.jimmy.pool`
- Version: `1.1` (version code `2`)
- No internet permission; only vibration permission.
- Three.js is bundled under the MIT license: [third-party license](THIRD-PARTY-LICENSE.txt).
- This repository distributes builds without private signing keys or user data.
