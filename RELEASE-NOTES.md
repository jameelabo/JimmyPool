# Jimmy Pool 1.1

- English app name: Jimmy Pool.
- English is the default, with a saved Arabic/English choice in the menu.
- Translated instructions, settings, results, errors, numbers and native exit prompts.
- Current match, including a moving shot, wins and difficulty are preserved.

Android 8.0+. Install updates without uninstalling.

العربية: الاسم Jimmy Pool والإنجليزية افتراضية مع اختيار العربية من القائمة. المباراة والنتائج محفوظة عند التحديث فوق الحالية.
